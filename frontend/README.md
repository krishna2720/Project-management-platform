# Workspace frontend

React, Vite, Tailwind CSS, and Axios frontend for the Project Management Platform.

## Folder structure

```text
project_management/
├── src/                 # Express backend
├── node_modules/        # Backend dependencies
├── frontend/
│   ├── src/             # React app, pages, components, API, and auth context
│   ├── node_modules/    # Frontend dependencies
│   └── dist/            # Generated by the production build
└── package.json         # Backend dependencies and scripts
```

Keep each `node_modules` beside its own `package.json`; neither belongs inside `src`.

## Run locally

Start the Express backend and MongoDB first. The backend defaults to port `3000`.

```sh
npm install
npm run dev
```

The Vite development server runs on port `5173` and proxies `/api` requests to the backend at `http://localhost:5000` by default. If the backend runs on another port, set `VITE_BACKEND_URL` in the frontend environment.

For a deployed backend, set `VITE_API_URL` to its API base URL, such as `https://api.example.com/api/v1`.

## Other commands

```sh
npm run build
npm run lint
npm run preview
```

The UI connects to the existing `/api/v1/auth`, `/api/v1/projects`, `/api/v1/tasks`, and `/api/v1/notes` endpoints.
